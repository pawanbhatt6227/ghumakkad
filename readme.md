# Ghumakkad

A full-stack travel and group-exploration platform that helps people discover trips, connect with verified travelers, and explore places together.

## Technology Stack

- **Frontend:** React, TypeScript
- **Backend:** Python, Django, Django REST Framework
- **Database:** PostgreSQL
- **Version Control:** Git

## Project Structure

- `frontend/` — Web application
- `backend/` — Backend APIs and business logic
- `README.md` — Project documentation
